# ADR 0001 — Record architecture decisions

- Status: accepted
- Date: 2026-09-29

## Context
The project will grow across a backend, a mobile app and later a web app. Decisions
need to be traceable so future contributors understand *why* things are the way they are.

## Decision
We record significant decisions as lightweight ADRs in `docs/adr/NNNN-title.md`.

## Consequences
Every non-trivial technical choice (stack, data store, integrations) gets an ADR.
